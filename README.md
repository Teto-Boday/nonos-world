# Nono's World 🌍

تطبيق كيوت للفلوس والجدول والمذاكرة والنفسية ودفتر الحكايات، مع ربط الشريك.

- **الموقع والتطبيق على الويب:** https://teto-boday.github.io/nonos-world/
- **أندرويد وويندوز:** من [Releases](https://github.com/Teto-Boday/nonos-world/releases/latest)

## التركيب
- `web/` كود التطبيق (Firebase Auth + Firestore).
- `site/` موقع التحميل.
- `firestore.rules` قواعد الحماية (تتحط في Firebase Console ← Firestore ← Rules).
- `electron/` نسخة الويندوز، `capacitor.config.json` نسخة الأندرويد.
- `.github/workflows/` بيبني وينشر كل حاجة أوتوماتيك.
